# 题目一提交说明：酱油风味物质 Lasso 降维

> 运行方式：`python lasso_analysis.py`（依赖见 `requirements.txt`，Python ≥ 3.10）。
> 结果可用 `random_state = 42` 复现；`LassoCV` 使用 10 折交叉验证、200 个 λ、`max_iter=20000`。

## 一、总体思路

- **数据**：288 个观测（48 样品 × 6 次重复）× 40 个风味指标，目标变量为咸味评分。
- **为什么在标准化数据上做**：Lasso 的 L1 惩罚对各变量对称，若量纲不同（NaCl 为 g/100 mL 量级、5'-GMP 可能为 mg/100 mL 量级），惩罚会不公平地偏向小量纲变量。因此直接使用提供的 Z-score 标准化数据；脚本中还做了一步自查——**从原始数据手工计算 Z-score（ddof=0）与标准化文件的最大绝对差为 5×10⁻¹⁵**，确认两者一致。
- **流程**：`LassoCV`（10 折）→ 图 1 系数路径 + 图 2 交叉验证误差曲线（MSE，误差棒为标准误 `std/√10`）→ 图 3 λmin 下非零系数条形图。
- **合理性与参考值核对**：λmin、λ1se、保留指标数与被压缩为 0 的指标均与任务书自查参考值一致（见下）。

## 二、附加要求 1：λmin 与 λ1se 的数值

| 准则 | λ | log10(λ) | 含义 |
| --- | --- | --- | --- |
| **λmin** | **0.000530831** | **-3.275** | 交叉验证 MSE 最小 |
| **λ1se** | **0.00185212** | **-2.732** | 一倍标准误准则（最简约模型） |

（任务书参考值：λmin ≈ 0.000531、log10(λmin) ≈ -3.28；log10(λ1se) ≈ -2.75，均一致。）

## 三、附加要求 2：λmin 下保留的指标个数

40 个指标中保留 **36 个**（系数非零），4 个被压缩为 0。

## 四、附加要求 3：被压缩为 0 的指标

| 英文名 | 中文名 | 类别 |
| --- | --- | --- |
| Gly | 甘氨酸 | 游离氨基酸 |
| Leu | 亮氨酸 | 游离氨基酸 |
| Thr | 苏氨酸 | 游离氨基酸 |
| Val | 缬氨酸 | 游离氨基酸 |

（与任务书参考值一致：甘氨酸、亮氨酸、苏氨酸、缬氨酸。）4 个全部为游离氨基酸——在 18 个氨基酸中，这 4 个与咸味评分的偏相关贡献被其余指标（其余氨基酸、核苷酸）线性替代，L1 惩罚将其系数压缩为 0。

## 五、附加要求 4：为什么选择 λmin 而不是 λ1se

结论：**选 λmin 作为最终的降维结果**，依据如下（结合图 1、图 2 的实际数字）：

1. **图 2 显示两个模型的预测能力在统计上不可分辨**：λ1se 处的 CV MSE 为 0.0882，仅比最小值 0.0722 高 0.0160，而最小值的标准误为 0.0165——差值恰好用一个标准误就完全覆盖，这正是 1-SE 准则的边界含义，不代表 λ1se 真的更差，也不代表 λmin 显著更好。
2. **图 1（与数值核对）显示 λ1se 的稀疏化收益很小**：λ1se 保留 33 个指标（把 Ile、Phe、Tyr、Cys 等也压为 0），只比 λmin 的 36 个少 3 个——用一个完整的标准误误差预算去换 3 个指标的精简，性价比低。
3. **本任务的目的决定了"审慎筛选"优于"激进裁剪"**：降维的下一步是把筛选结果交给 GB、RF、SVR 等非线性模型，这些模型自身具备特征选择与抗共线性能力，保留几个仍携带有用信息的氨基酸（Ile、Phe、Tyr、Cys 在非线性组合中可能有效）比提前丢弃更稳妥；Lasso 在这里的职责是剔除**明显冗余**的指标，而不是追求极致稀疏。
4. **λ1se 的适用场景是"测量成本/模型复杂度优先"**（如希望仪器少测几个指标），但在此数据上它只换来 3 个指标的减少，收益不足以补偿误差预算，因此最终采用 λmin。
